## 🗂️ Estrutura Padronizada por Empresa (Padrão Ouro)

Cada pasta de empresa dentro de `tech_dev/`, `marketing_audiovisual/` ou `suporte_operacoes/` segue rigorosamente a convenção obrigatória:

```text
carreira/vagas_analisadas/[trilha]/[empresa]/
├── analise_match.md                            # 1. Diagnóstico técnico detalhado (% aderência)
├── relatorio_match_[empresa].pdf                # 2. Relatório visual executivo em PDF com gráficos e pretensão CLT/PJ
├── curriculo_[empresa].md                       # 3. Currículo customizado em Markdown
├── Curriculo_Fabio_Rodrigues_[Area_ou_Cargo].pdf# 4. Currículo oficial em PDF (Harvard Tech / ATS)
├── cover_letter.md                             # 5. Carta de apresentação formal em Markdown
├── Cover_Letter_Fabio_Rodrigues.pdf             # 6. Cover Letter formal timbrada em PDF
├── Cover_Letter_Fabio_Rodrigues.docx            # 7. Cover Letter formal timbrada em Word DOCX
└── carta_apresentacao_recruiter.md             # 8. Mensagens prontas para Recruiter/Tech Lead no LinkedIn
```
