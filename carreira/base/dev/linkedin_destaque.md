🚀 Do Conceito à Prática: Como construí o NOVA, um Sistema Multi-Agente com Java 21, Spring Boot 3 e Spring AI (MCP)

Nos últimos meses, decidi transformar meus estudos no Bootcamp Santander 2026 (DIO) em engenharia real. O resultado é o NOVA — meu ecossistema multi-agente pessoal e profissional que une orquestração de IA com microsserviços Java modernos.

Em vez de criar apenas um chatbot simples, o desafio foi construir uma arquitetura sólida e desacoplada:

🏛️ 1. Clean Architecture & Java 21
• Domínio puro e isolado de frameworks externos, utilizando Ports & Adapters.
• DTOs imutáveis com Java 21 Records e validação declarativa com Bean Validation.
• Tratamento global de exceções padronizado com RFC 7807 (ProblemDetails).

🤖 2. Model Context Protocol (MCP) com Spring AI
• Construção de um servidor MCP nativo no Spring Boot 3.3+.
• Ferramentas (@Tool) expostas para que modelos de IA executem cadastro, listagem e cálculos analíticos financeiros em tempo real com tipagem estrita.

💾 3. Persistência Física & Resiliência
• Banco de dados H2 configurado em arquivo físico persistente, garantindo conciliação transacional ACID e preservação de dados entre reinicializações.
• Isolamento completo do banco em memória para suítes de testes automatizados com JUnit 5 e Mockito.

⚡ 4. Scaffolding & Automação de Código
• Desenvolvi um gerador CLI em Python que cria toda a estrutura de uma nova feature (Domain Model, Port, Record DTOs, UseCases, Entity JPA, Adapter e Teste Unitário) com apenas 1 comando.
• Checklist formal de Code Review integrado ao fluxo de trabalho.

Além do NOVA, também desenvolvi a Sofia (Voice AI Outbound Agent para a Infinit Tecnologia via Vapi + OpenAI + RAG + Webhooks), aplicando IA em fluxos comerciais reais de ponta a ponta.

O código limpo, a separação de responsabilidades e os testes automatizados são a base de qualquer entrega de valor.
